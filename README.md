# مدير التعليم العائلي (Smart Family Education Manager)

المجلد الرئيسي للمشروع: `F:\Family-Education-App`

## الحالة الحالية (صريحة)
- قاعدة البيانات (Supabase، مشروع `family-edu-manager`، خطة مجانية): **مُنفَّذة ومُختبَرة** (الجداول، الفهارس، سياسات RLS، رموز الدعوة). تم اختبار RLS فعلياً.
- الكود (المرحلتان 1 و2: تسجيل الدخول والتسجيل ولوحتا ولي الأمر والطالب): **مكتوب لكنه لم يُبنَ ولم يُشغَّل بعد.** تثبيت الحزم في بيئتي التجريبية لم يكتمل، لذلك لا يوجد حالياً دليل على نجاح `next build`.
- تم إصلاح عيب واحد معروف: إضافة الحزمة `server-only` إلى `package.json` (كانت مستخدمة في `lib/supabase/admin.ts` وغير مُدرجة).
- لا يوجد بعد: PWA manifest، المراحل 3 إلى 8.

## التشغيل على جهازك
1. ثبّت Node.js 20 أو أحدث.
2. افتح المجلد في الطرفية ثم:
   ```
   npm install
   npm run build
   npm run dev
   ```
3. افتح `.env.local` وضع قيمة `SUPABASE_SERVICE_ROLE_KEY` (من Supabase: Project Settings > API). لا تشاركها مع أحد ولا ترفعها على Git.
4. جرّب: تسجيل ولي أمر، ثم إضافة ابن، ثم تسجيل الطالب برمز الدعوة.

إذا ظهر خطأ في `npm run build` احفظه في `logs\build.log` وأرسله لي لإصلاحه.

## البنية
- `app/` الصفحات ومسارات API، `components/` المكوّنات، `lib/supabase/` عملاء Supabase
- `supabase/migrations/` ملفات SQL كما نُفّذت على قاعدة البيانات (001، 002، 003)
- `logs/` سجلات البناء والاختبار

## قرارات التصميم
- كل جدول يحمل `family_id` ليكون فحص الصلاحيات بسيطاً وسريعاً.
- الطالب يقرأ بياناته فقط، ولا يستطيع كتابة النقاط أو الدرجات أو قراءة مفاتيح الإجابة، ولا يحذف حسابه.
- حذف الطالب وحسابه عبر مسار خاص بولي الأمر فقط.
- دوال RLS الثلاث (`my_family`, `is_parent`, `my_student`) قابلة للاستدعاء من المستخدمين المسجلين عمداً؛ تُرجع معلومات المستخدم نفسه فقط.
